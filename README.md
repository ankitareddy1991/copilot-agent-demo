# Copilot Agent Demo

A simple command-line calculator written in Python. It supports addition, subtraction, multiplication, and division, including a check that prevents division by zero.

## Usage

Run the calculator with:

```bash
python main.py
```

Enter two numbers and one of the supported operations: `+`, `-`, `*`, or `/`.

## Requirements

Python 3.8 or later. No third-party packages are required.
